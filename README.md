# HeavenBound — mises à jour

Ce dépôt ne contient que ce que le jeu télécharge au lancement :

- `version.json` : dernière version publiée (v11)

Installer le jeu : télécharger [heavenbound.apk](https://github.com/Manakil-studio/HeavenBound-MAJ/raw/main/heavenbound.apk) sur le téléphone et l'ouvrir.
